## About me

I'm Cyan Peng (Chane). I build software for optical and photonic equipment, and for production test. The same software runs the measurements and the interface on the tool.

I write it in C# on .NET, using WPF and MVVM for the interface, with sequencing and device control underneath.

The real systems are not in a public repository.

## Current Focus

- **Equipment software.** Optical and photonic equipment, and production test.
- **Process tooling.** Motion-control software, GDSII utilities, and digital-twin models.
- **Development practice.** Experiments in an AI-first software lifecycle, with the output checked against how the hardware behaves.

C# · .NET · WPF · MVVM · motion control · GDSII
